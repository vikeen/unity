# Unity

Personal Unity experiments and projects.

## Getting started

1. Open **Unity Hub**.
2. **New project** (or **Add** an existing one) and point it at this folder, or create a subfolder here for each game (e.g. `my-game/`).
3. Commit often; `Library/` and other generated paths are ignored via `.gitignore`.

Remote: [github.com/vikeen/unity](https://github.com/vikeen/unity)
